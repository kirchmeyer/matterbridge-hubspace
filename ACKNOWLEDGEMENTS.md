# Acknowledgements

Matterbridge Hubspace is a Matterbridge port derived from the Hubspace integration work in the Homebridge community.

Project lineage:

- [homebridge-hubspace](https://github.com/sajmonr/homebridge-hubspace), the original Hubspace Homebridge project credited by the upstream repository.
- [JakeAi/homebridge-hubspace](https://github.com/JakeAi/homebridge-hubspace), which improved code structure and token handling.
- [fiestachickens/homebridge-home-depot-hubspace](https://github.com/fiestachickens/homebridge-home-depot-hubspace), the immediate upstream repository and retained Git history for this port.
- [Matterbridge](https://github.com/Luligu/matterbridge), which provides the Matter plugin runtime and APIs.

The retained repository history credits Adam Simonicek as the primary author of the original implementation and Cyrus Keck as the maintainer of the immediate upstream fork. Their Hubspace API discovery and device mappings form the foundation of this port.

Hubspace is a Home Depot platform backed by Afero services. This project is independent and is not affiliated with or endorsed by Home Depot, Hubspace, Afero, or Matterbridge.
