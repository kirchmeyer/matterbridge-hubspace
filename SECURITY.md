# Security Policy

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities or include credentials, tokens, account IDs, device IDs, Matter setup codes, or other sensitive information in a report.

Use [GitHub private vulnerability reporting](https://github.com/kirchmeyer/matterbridge-hubspace/security/advisories/new). Include the affected version, impact, reproduction steps, and any suggested mitigation.

Hubspace cloud API availability and behavior are controlled by third parties. Service outages and upstream API changes that do not expose data or cross a security boundary should be reported as regular bugs.

## Supported versions

Until the first stable release, security fixes are provided on the latest published `0.x` release only.
